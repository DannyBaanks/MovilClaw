3 Tu repositorio

Pega la URL del repo. Sin cuenta, solo funciona con repos públicos; con tu cuenta, también con los privados. El sandbox abre la red solo para traerlo y la cierra al terminar.

5 Candado

Escribe una frase secreta. Con ella se cifra el trabajo real del sandbox, y la frase nunca sale de este navegador. El servidor solo guarda un archivo que no puede abrir.

6 Reanudar un trabajo

Elige el archivo que descargaste: el sello .sealed.json o el .tar.gz del trabajo. Si está sellado se abre aquí mismo con la frase del candado — la frase nunca sale de este navegador — y el servidor solo recibe el archivo ya abierto para montarlo en el sandbox elegido.

7 Publicar tu trabajo

Empuja los cambios a una rama movilclaw/… y abre un PR. Nunca a main, y el PR no se fusiona solo: eso es decisión tuya.
